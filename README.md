# Відключення світла — віджет (Київська область, ДТЕК КРЕМ)

Збірка APK: вкладка **Actions** → останній запуск «Build APK» → внизу **Artifacts → outages-apk**.
Якщо збірка впала — відкрийте лог кроку `gradle assembleDebug` і надішліть текст помилки.

Дані беруться з сайту dtek-krem.com.ua через прихований WebView.
Якщо ДТЕК змінить формат — правити потрібно лише `DtekClient.kt` та `ScheduleParser.kt`.
